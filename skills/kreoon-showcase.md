# SKILL: Kreoon Showcase

## Propósito

Crear contenido que demuestre el valor de Kreoon sin caer en "sales pitch", usando casos reales, workflows y resultados específicos.

---

## Cuándo Usar

- Posts sobre Pilar 2 (IA Aplicada)
- Cuando un feature nuevo de Kreoon esté listo
- Casos de éxito con usuarios beta
- Comparativas IA (Kreoon vs. ChatGPT/otros)
- Educational content sobre research automatizado

---

## Regla de Oro

**80% Educación + 20% Producto**

❌ "Kreoon es increíble, úsalo"
✅ "Así es cómo automatizo research de mercado. Kreoon hace X, Y, Z. Tú puedes hacer A, B, C manual si prefieres"

**Siempre dar alternativa gratuita/manual.** Esto genera confianza.

## Formatos de Showcase

### Formato 1: Workflow Real (BTS)

**Estructura:**
1. Problema específico que tenías
2. Cómo lo resolvías antes (manual, lento)
3. Cómo Kreoon lo automatiza
4. Resultado comparado (tiempo/calidad)

**Ejemplo:**
```
PROBLEMA:
Estrategia de contenido para cliente tomaba 8-10 horas.
- Research de industria: 3hrs
- Análisis competencia: 2hrs
- Definir ángulos: 2hrs
- Estructurar calendario: 3hrs

ANTES KREOON:
Todo manual. Google Docs, hojas de cálculo, Perplexity suelto.

CON KREOON:
- Research automatizado: 15min
- Análisis competencia: 10min
- Ángulos sugeridos: Instantáneo
- Calendario estructurado: 20min

TOTAL: 45min vs. 10hrs

[Screenshot de Kreoon generando research]

¿Cómo? Kreoon conecta Perplexity + Gemini + estructura
personalizada para estrategia de contenido.

Alternativa sin Kreoon:
Puedes usar Perplexity solo + plantilla manual.
Te tomará ~3hrs pero funciona.
```

## Storytelling + Kreoon

### Historia: Por Qué Nació Kreoon
```
[HOOK]
Kreoon no nació para "vender software". Nació de frustración.

[PROBLEMA]
2023, haciendo estrategias de contenido para 8 clientes/mes.
Cada una: 10 horas. 80 horas/mes solo en research.
Probé ChatGPT. Resultado: Genérico, sin profundidad.
Probé Perplexity solo. Mejor, pero desorganizado.

[INSIGHT]
El problema no era "falta de IA". Era falta de WORKFLOW.
IA existe. Pero conectar tools + estructura + proceso específico
para estrategia de contenido... no existía.

[SOLUCIÓN]
Construí Kreoon. Para mí. Luego lo usó mi equipo.
Luego algunos clientes preguntaron: "¿Puedo usar eso?"
Hoy es producto. Pero nació de resolver MI problema.

[LECCIÓN]
Los mejores productos nacen de frustración propia.
Si tú tienes un problema recurrente, resuélvelo.
Probablemente otros tienen el mismo.
```
