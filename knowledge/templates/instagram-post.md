# Template: Instagram Post

**Plataforma:** Instagram (Feed)
**Formatos:** Foto única, carrusel, Reel con caption
**Propósito:** Referencia de estructura para el copywriter

---

## Estructura Base

```
[HOOK — Línea 1]
Máximo 15 palabras. Lo único visible antes del "ver más".

[ESPACIO]
(salto de línea)

[CUERPO]
Desarrollo del tema.
Párrafos de 1-3 líneas máximo.
Una idea por párrafo.

[ESPACIO]

[CIERRE]
Reflexión o lección práctica.

[ESPACIO]

[CTA]
Pregunta abierta o acción suave.

[HASHTAGS]
3-8 hashtags. Al final, separados del texto.
```

---

## Variantes por Tipo de Post

### Tipo 1: Educativo

```
[Afirmación contraintuitiva o dato impactante]

[Contexto: por qué importa]

[Punto 1]
[Punto 2]
[Punto 3]

La diferencia real: [insight clave]

¿Cuál de estos aplica en tu negocio?

#hashtag1 #hashtag2 #hashtag3
```

**Ejemplo:**
```
Live shopping no es TikTok Shop.

La mayoría confunde la plataforma con el modelo de negocio.

TikTok Shop: plataforma de venta
Live Shopping: sistema de ventas multi-plataforma 24/7

La diferencia:
→ TikTok Shop = canal
→ Live Shopping = sistema

Con el sistema correcto, vendes en cualquier plataforma.
Sin sistema, dependes de una sola.

¿Cuál estás usando?

#liveshopping #tiktokshop #ecommerce #latam #ventas
```

### Tipo 2: Storytelling Personal

```
[Momento específico del pasado — contexto emocional]

[Qué estaba pasando / el problema]

[Punto de quiebre o decisión]

[Qué cambió]

[Lección extraíble HOY]

[Pregunta de conexión]
```

**Ejemplo:**
```
Hace 3 años no podía pagar el arriendo.

Tenía dos negocios "funcionando" que en realidad me estaban quebrado.
Estaba tan ocupado que no tenía tiempo para pensar.

Un viernes me senté a revisar los números reales.
No los que quería ver — los reales.

Resultado: estaba trabajando 70 horas semanales para ganar menos que un empleado.

Ese día decidí parar, desmontar lo que no funcionaba y reconstruir con sistema.

Hoy facturo más, trabajo menos, y tengo tiempo para mi familia.

La diferencia no fue trabajar más duro.
Fue trabajar con sistema.

¿Estás revisando los números reales de tu negocio?
```

## CTAs Recomendados para Alexander

**Suaves (más naturales):**
- "¿Qué piensas?"
- "¿Cuál es tu experiencia?"
- "¿Te ha pasado?"
- "Cuéntame cómo lo estás manejando."
- "¿Cuál de estas te identifica más?"

**Directos (cuando hay un recurso):**
- "Si quieres que lo veamos juntos, escríbeme al DM."
- "Tengo una sesión disponible esta semana si quieres profundizar."
- "El enlace para explorar Kreoon está en el bio."

**Evitar:**
- "¡Dale like si estás de acuerdo!" 
- "Comparte con alguien que necesite esto"
- "Sígueme para más contenido"
- CTAs urgentes o con presión

## Especificaciones Técnicas

| Elemento | Especificación |
|---------|---------------|
| Longitud caption | 150-2200 caracteres |
| Sweet spot | 800-1200 caracteres |
| Primera línea | Máx 15-20 palabras (antes del "ver más") |
| Emojis | Solo si refuerzan — nunca decorativos |
| Hashtags | Al final, sin punto antes |
| Saltos de línea | Generosos — mejoran legibilidad |
| Párrafo máx. | 3 líneas |

---

## Notas de Voz (Alexander)

- Sin "¡Hola a todos!" ni saludos iniciales — directo al hook
- Sin exclamaciones exageradas (máximo 1 por post si aplica)
- Expresiones paisas: máximo 2-3 por post, naturales
- Tono: como explicarle a un amigo inteligente, no en clase
- Números específicos > aproximaciones vagas ("23% más" > "mucho más")
