## 1. Los 3 Cerebros (Triuno) — La Puerta de Entrada

El contenido debe pasar 3 filtros cerebrales en orden. Si falla en uno, no llega al siguiente.

```
REPTILIANO → LÍMBICO → NEOCÓRTEX
(¿Me importa?) → (¿Me emociona?) → (¿Lo comparto?)
```

### Reptiliano — El Guardián de la Atención
- Controla: supervivencia, patrones, atención primaria
- Se activa ante: novedad, movimiento, contraste, rostros, peligro
- Decisión en: **50–200 ms** (antes de que el humano sea consciente)
- Para pasar este filtro: **pattern interrupt en el primer frame**

### Límbico — El Generador de Emoción
- Controla: emociones, memoria, conexión social
- Se activa ante: historias personales, emociones de alta activación, identidad
- Para pasar este filtro: **alta activación emocional sostenida**

### Neocórtex — El Tomador de Decisión
- Controla: razonamiento, lenguaje, decisión de compartir
- Se activa ante: valor práctico, lógica clara, "esto les sirve a los demás"
- Para pasar este filtro: **utilidad + bajo esfuerzo cognitivo**

## 2. El Sistema de Atención (RAS) — Por Qué el 99% es Ignorado

El **Sistema de Activación Reticular (RAS)** filtra ~99% de los estímulos.
Solo 4 cosas lo bypasean automáticamente:

| Disparador | Mecanismo | Aplicación en contenido |
|---|---|---|
| **Novedad** | Hipocampo detecta patrones nuevos y los marca como "prioritarios" | Estructura inesperada, afirmación contrarian, dato que contradice creencia |
| **Relevancia personal** | "Esto me afecta a MÍ" activa el self-referential processing | Hablar directamente a un dolor/deseo específico de la audiencia |
| **Amenaza / pérdida** | Amígdala responde primero, antes de procesar el contexto | "El error que te está costando X" / "Lo que ya estás perdiendo" |
| **Alta carga emocional** | Señal de norepinefrina = "esto importa, recuérdalo" | Cualquier emoción de alta activación (ver sección 3) |

**Regla práctica:** El hook debe disparar al menos 1 de estos 4 en los primeros 3 segundos.

## 3. Emociones y Probabilidad de Compartir — Berger & Milkman (2012)

Estudio en 7,000 artículos del NYT. Descubrimiento clave:
**No es el tipo de emoción lo que determina si algo se comparte — es el nivel de ACTIVACIÓN.**

```
ALTA ACTIVACIÓN → COMPARTE
BAJA ACTIVACIÓN → NO COMPARTE
```

### Tabla de emociones por activación y shareability

| Emoción | Activación | Efecto en compartir | Aplicación Alexander |
|---|---|---|---|
| **Asombro (Awe)** | 🔴 Muy alta | +30% sobre baseline | Historia de transformación masiva, dato impactante de mercado |
| **Curiosidad** | 🔴 Alta | +25% | Curiosity gap, información que "nadie te dice" |
| **Diversión / Humor** | 🔴 Alta | +25% | Contraste inesperado, analogía ingeniosa |
| **Admiración** | 🟠 Media-alta | +20% | Resultado real de Alexander o cliente |
| **Indignación (Anger)** | 🟠 Media-alta | +20% | Contrarian ("te mintieron"), verdad incómoda — usar con precaución |
| **Ansiedad** | 🟠 Media | +15% | Error que están cometiendo ahora mismo |
| **Identificación** | 🟠 Media | +15% | "Como yo hace 3 años", espejo de situación actual |
| **Contentamiento** | 🟡 Baja | -5% | No compartir |
| **Tristeza** | 🔵 Muy baja | -15% | No compartir (puede crear conexión pero no viralidad) |

### Regla para Alexander
- **Apostar por:** Asombro + Curiosidad + Identificación (compatibles con voz tranquila)
- **Usar con criterio:** Indignación (funciona pero puede alejar audiencia si es muy fuerte)
- **Evitar como pilar:** Contenido de entretenimiento puro sin activación emocional

## 4. Dopamina y el Loop de Curiosidad (Loewenstein, 1994)

La **teoría del information gap** explica por qué el curiosity gap funciona:

```
Sé que existe información → No la tengo → Tensión (dopamina anticipatoria)
→ Busco resolverla → Resolución = dopamina de recompensa → Satisfacción → COMPARTO
```

### Las 3 fases del loop dopaminérgico en contenido

**Fase 1 — Apertura del gap (Hook)**
Crear la sensación de "me falta algo importante que debería saber."
- "Hay un error que el 90% de emprendedores comete en live shopping..."
- El cerebro entra en estado de anticipación.

**Fase 2 — Mantenimiento del gap (Cuerpo)**
No resolver demasiado rápido. Sostener la tensión con micro-revelaciones.
- Cada punto del contenido entrega valor PARCIAL pero mantiene abierta la pregunta central.
- El cerebro libera dopamina en pequeñas dosis = engagement sostenido.

**Fase 3 — Resolución (Cierre)**
Entregar el payoff prometido + dejar una pregunta residual (para que vuelvan).
- La resolución satisfactoria activa la memoria emocional (amígdala + hipocampo).
- Contenido bien resuelto = más probabilidad de compartir.

**Error más común:** Dar el resultado en el hook. Sin gap, no hay curiosidad, no hay dopamina.

## 5. Neuronas Espejo — Por Qué el Storytelling Personal Funciona

Las **neuronas espejo** hacen que el cerebro del espectador active las mismas regiones neurales que el protagonista de la historia. Cuando Alexander cuenta una historia personal:

- El cerebro de quien ve **experimenta** la historia, no solo la procesa
- Esto genera **empatía neurológica** (no solo emocional)
- La empatía neurológica = vínculo = memoria = share

### Cómo activar neuronas espejo

| Técnica | Mecanismo | Ejemplo para Alexander |
|---|---|---|
| **Detalle sensorial específico** | El cerebro simula la sensación | "Eran las 2am. Café frío. Laptop parpadeando." |
| **Emoción nombrada, no descrita** | Contagio emocional directo | "Sentí pánico." vs "Fue difícil" |
| **Situación universal** | Mayor porcentaje del cerebro "se ve ahí" | "Ese momento en que trabajas mucho y no avanza" |
| **Rostro visible + contacto visual** | Activa el sistema de reconocimiento facial | Grabar mirando a la cámara, no al guion |

## 6. Moneda Social (Berger — STEPPS) — Por Qué la Gente Comparte

Las personas comparten contenido que les hace verse bien frente a los demás.
El contenido viral generalmente tiene al menos 1 de estas 6 propiedades (STEPPS):

| Propiedad | Qué es | Aplicación Alexander |
|---|---|---|
| **S — Social Currency** | Compartirlo me hace ver inteligente/adelantado | Datos no-conocidos de live shopping LATAM, IA aplicada real |
| **T — Triggers** | Me lo recuerda algo de mi día a día | Vincular el tema a situaciones cotidianas del emprendedor |
| **E — Emotion** | Alta activación emocional (ver sección 3) | Asombro, curiosidad, identificación |
| **P — Public** | Comportamiento visible = imitable | Mostrar lo que haces (BTS, demos, resultados) |
| **P — Practical Value** | Es genuinamente útil / aplicable | Valor real, aplicable sin contratar a Alexander |
| **S — Stories** | Envuelto en narrativa, no en datos | Siempre historia primero, dato después |

**Regla de oro:** Cuanto más STEPPS tiene el contenido, mayor probabilidad viral.
Contenido con 4+ propiedades = altamente compartible.

## 7. Carga Cognitiva y Facilidad de Procesamiento

**Efecto de fluidez de procesamiento (Alter & Oppenheimer, 2006):**
Lo que es fácil de entender PARECE más verdadero y más valioso.

```
Alta carga cognitiva → El cerebro lo descarta
Baja carga cognitiva → El cerebro lo acepta como verdad → Comparte
```

### Reglas para reducir carga cognitiva

| Problema | Causa | Solución |
|---|---|---|
| Frases largas | Sobrecargan memoria de trabajo | Máximo 12-15 palabras por oración |
| Ideas abstractas | El cerebro no puede "ver" la idea | Siempre un ejemplo concreto por concepto abstracto |
| Muchos puntos | Capacidad de trabajo: 7±2 chunks (Miller) | Máximo 5 puntos por pieza de contenido |
| Jerga sin contexto | El cerebro busca definición en vez de absorber | Definir en la misma oración: "IA aplicada = IA en un proceso real, no ChatGPT" |
| Transiciones abruptas | El cerebro pierde el hilo | Micro-puentes entre ideas: "Y eso conecta con..." |

## 8. Neurociencia del Hook Visual (Video — 0 a 3 segundos)

El cerebro procesa imagen visual antes del audio. Orden de procesamiento:

```
Movimiento → Contraste → Rostro → Expresión → Texto en pantalla → Audio
```

### Checklist visual para los primeros 3 segundos

| Elemento | Por qué funciona | Recomendación Alexander |
|---|---|---|
| **Movimiento en frame** | Corteza visual dorsal: detección de movimiento es automática | Gesto de mano, cambio de encuadre, cut rápido |
| **Contraste alto** | Mayor señal al tálamo visual | Ropa que contraste con el fondo, iluminación lateral |
| **Rostro visible** | Área fusiforme facial: se activa antes de conciencia | MCU desde el inicio, no introducción del entorno |
| **Expresión emocional** | Contagio emocional automático (15-35ms) | Cara seria = autoridad. Cara curiosa = empatía |
| **Texto en pantalla** | Refuerza procesamiento dual (visual + auditivo) | Palabra clave del hook en texto, primeros 2 segundos |
| **Eye contact directo** | Activa red neuronal social, genera confianza | Mirar al lente, no a los ojos de la cámara |

## 9. Neurociencia del Audio (Primeros 500ms)

El sistema auditivo decide si seguir escuchando en los primeros **500 milisegundos**.

| Factor | Efecto | Aplicación |
|---|---|---|
| **Tono de voz inesperado** | Orienting response: el cerebro redirige atención | Empezar en volumen ligeramente más bajo de lo normal, luego subir |
| **Silencio previo** | El silencio súbito activa alerta | 0.5-1 segundo de silencio antes de la primera palabra |
| **Primera palabra impactante** | Efecto de primacía: lo primero se recuerda más | Empezar con el concepto central, no con saludo |
| **Cadencia irregular** | Evita que el cerebro se "adormezca" con patrones | Variar velocidad: pausa + aceleración + pausa |
| **Voz con textura** | Más procesamiento en corteza auditiva = más atención | Hablar desde el pecho, no desde la garganta |

## 10. El Arco Emocional Óptimo para Retención

Estudios de YouTube Analytics y retención de video muestran que el arco emocional que mayor retención genera:

```
TENSIÓN (hook) → MICRO-ALIVIO (te entiendo) → TENSIÓN MAYOR (el error/problema)
→ ESPERANZA (existe solución) → RESOLUCIÓN (el método) → SATISFACCIÓN (el resultado)
```

Este arco activa **dopamina + norepinefrina + serotonina** en secuencia.

### Aplicación por pilar Alexander

**Pilar 1 — Mentalidad + Fe:**
Tensión = "Trabajas mucho y no avanzas" → Identificación = "Yo también estuve ahí" → Esperanza = "Hubo un cambio" → Resolución = la lección → Satisfacción = "Tú puedes hacer lo mismo"

**Pilar 2 — IA + Estrategia:**
Tensión = "Pierdes X horas por semana" → Problema = "La mayoría lo hace mal" → Método = el sistema IA → Resultado = tiempo/dinero recuperado → CTA suave

**Pilar 3 — Live Shopping:**
Tensión = "El live shopping que crees conocer no existe" → Contraste = "Lo que sí funciona" → Demostración = el stack real → Resultado = ventas 24/7 → Posibilidad = tú también puedes
