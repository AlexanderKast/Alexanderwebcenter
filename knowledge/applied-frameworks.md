## 1. NEUROVENTAS — Gatillos Mentales en Contenido

**Skill global:** Neuroventas (Cialdini, gatillos mentales, cerebro triuno)
**Aplica en:** `agents/copywriter.md`, CTAs, hooks, slides de cierre en carruseles

### Los 7 Gatillos Más Efectivos para Contenido Orgánico

| Gatillo | Cómo activarlo en contenido de Alexander | Ejemplo |
|---------|------------------------------------------|---------|
| **Reciprocidad** | Dar valor real ANTES de pedir. Nunca al revés. | Carrusel con framework completo → CTA suave al final |
| **Prueba social** | Casos reales, números concretos, testimonios | "12 de 15 clientes lograron X" |
| **Autoridad** | Credenciales específicas, no genéricas | "6+ años en ecommerce, co-fundé SICOMMER" |
| **Escasez** | Real, nunca falsa. Límite de cupos = verdad | "Máximo 4 sesiones/mes — quedan 2" |
| **Urgencia** | Basada en contexto, no en presión artificial | "LATAM está donde el dropshipping en 2018. Ahora." |
| **Afinidad** | Compartir valores, origen, luchas similares | Historia de quebrar SICOMMER → audiencia se identifica |
| **Compromiso** | Preguntas que generan micro-sí antes del sí grande | "¿Te identificas con esto?" → DM → Sesión |

### Cerebro Triuno Aplicado al Copy

```
REPTILIANO (supervivencia/instinto)
→ Actívalo con: Urgencia real, miedo a quedarse atrás, oportunidad limitada
→ Palabras: "Ahora", "hoy", "mientras duermes", "24/7", "te están superando"

LÍMBICO (emociones/relaciones)
→ Actívalo con: Historias personales, fracasos reales, fe, familia
→ Palabras: "Sentí", "aprendí", "cuando quebré", "mi equipo", "confío"

NEOCÓRTEX (lógica/datos)
→ Actívalo con: Comparaciones, métricas, frameworks, pasos claros
→ Palabras: "3x más", "de 1% a 15%", "en 7 pasos", "demostrado"
```

**Regla de Alexander:** Iniciar siempre con límbico (historia/emoción) → pasar a neocórtex (datos) → cerrar con reptiliano (acción).

## 2. COMPORTAMIENTO HUMANO — Audiencia de Alexander

**Skill global:** Comportamiento humano (Maslow, DISC, sesgos cognitivos)
**Aplica en:** `agents/strategist.md` (qué publica), `agents/copywriter.md` (cómo escribe)

### Maslow Aplicado a la Audiencia (25-40, LATAM, emprendedores)

```
NIVEL 5 — Autorrealización
"Quiero ser referente en mi industria, dejar legado"
→ Pilar: Mentalidad + Fe, Branding personal
→ Contenido: Historias de propósito, impacto, trascendencia

NIVEL 4 — Reconocimiento/Estatus
"Quiero que me vean como experto, que me respeten"
→ Pilar: IA Aplicada (ser el que usa tech), Live Shopping (pionero LATAM)
→ Contenido: Ser early adopter, casos de liderazgo, "avant-garde"

NIVEL 3 — Pertenencia
"Quiero conectar con otros que entiendan mi camino"
→ Pilar: Todos — comunidad de emprendedores
→ Contenido: "¿Te pasa esto también?", historias compartidas, comentarios

NIVEL 2 — Seguridad
"Quiero ingresos estables, no depender de un solo cliente"
→ Pilar: Live Shopping (ingresos 24/7), IA (eficiencia = más margen)
→ Contenido: Diversificación, automatización, flujos recurrentes

NIVEL 1 — Fisiológico/Básico
"Necesito generar dinero AHORA"
→ Contenido de entrada: Tutoriales rápidos, resultados inmediatos
→ CTA: Consultoría práctica, implementación directa
```

### Perfiles DISC de la Audiencia de Alexander

| Perfil | % est. audiencia | Qué necesita del contenido |
|--------|------------------|---------------------------|
| **D — Dominante** | 20% | Resultados, datos, sin rodeos. Formato: listas, métricas, directividad |
| **I — Influyente** | 30% | Historias, inspiración, comunidad. Formato: storytelling, reels, comentarios |
| **S — Estable** | 35% | Pasos claros, seguridad, sistema. Formato: tutoriales, carruseles paso a paso |
| **C — Concienzudo** | 15% | Detalle, lógica, prueba. Formato: comparaciones, casos, datos precisos |

**Implicación práctica:**
- Carruseles educativos = captura D + S + C
- Reels/historias personales = captura I + S
- Casos de estudio con datos = captura D + C
- Reflexiones de fe/mentalidad = captura I + S

### Sesgos Cognitivos a Usar (y Evitar)

**USAR (éticamente):**
- **Anclaje:** Mostrar el precio alto primero para que el real parezca razonable
- **Loss aversion:** "LATAM está perdiendo esta oportunidad mientras China ya hizo $500B"
- **Disponibilidad:** Repetir casos reales frecuentemente — lo que se recuerda fácil parece más probable
- **Efecto halo:** Si Alexander es creíble en IA, la audiencia transfiere esa credibilidad a live shopping

**EVITAR (no manipulación):**
- ❌ Urgencia falsa ("SOLO HOY" cuando siempre está disponible)
- ❌ Prueba social inflada (seguidores comprados, métricas falsas)
- ❌ Escasez artificial (cupos "limitados" que nunca se llenan)

## 3. COPYWRITING AVANZADO — Frameworks Complementarios

**Skill global:** Copywriting avanzado (AIDA, PAS, BAB, storytelling)
**Aplica en:** `agents/copywriter.md` (ya tiene AIDA/PAS — aquí va lo adicional)

### BAB (Before-After-Bridge) — Para Posts de Transformación

```
BEFORE: Describe el dolor actual del lector
→ Tan específico que piensen "está hablando de mí"

AFTER: Pinta el estado deseado con detalle sensorial
→ Tan vívido que lo deseen físicamente

BRIDGE: Tu solución como el puente entre los dos estados
→ Específico, creíble, alcanzable
```

**Ejemplo Alexander (Live Shopping):**
```
BEFORE:
"Trabajas 12 horas publicando contenido.
Haces lives cada semana hasta quedarte ronco.
Al final del mes, tus ventas son las mismas."

AFTER:
"Imagina revisar tu dashboard un lunes en la mañana.
Ver que mientras dormías, tu falso live vendió 23 unidades.
Tu equipo ya procesando los pedidos. Tú, tomando café."

BRIDGE:
"Eso es lo que construimos en LiveCake.
No más lives esporádicos. Sistema completo 24/7."
```

---

### PEP (Problema-Efecto-Prueba) — Para Posts de Autoridad

```
PROBLEMA: Identifica el problema que nadie quiere admitir
EFECTO: Escala las consecuencias de no resolverlo
PRUEBA: Demuestra que tienes la solución con evidencia real
```

**Ejemplo Alexander (IA):**
```
PROBLEMA:
"La mayoría usa IA para generar ideas genéricas.
Resultado: contenido que suena igual que todos."

EFECTO:
"Eso significa más tiempo creando, menos diferenciación,
y una audiencia que no sabe por qué seguirte a ti y no a otro."

PRUEBA:
"En UGC Colombia lo cambiamos: IA no para generar,
sino para analizar, estructurar y personalizar.
De 10 horas a 2 horas por estrategia. Diferentes resultados."
```

---

### Framework 4U (Urgente, Único, Ultra-específico, Útil) — Para Headlines

Cada titular de carrusel o hook debe cumplir máximo 4:

| U | Pregunta | Ejemplo malo | Ejemplo bueno |
|---|----------|-------------|---------------|
| **Urgente** | ¿Por qué importa ahora? | "Live shopping" | "Live shopping en LATAM: la ventana está abierta HOY" |
| **Único** | ¿Solo Alexander lo dice así? | "Usa IA" | "Kreoon: IA que habla en tu voz de marca" |
| **Ultra-específico** | ¿Evita lo vago? | "Gana más" | "De 1% a 15% de conversión" |
| **Útil** | ¿Promete valor real? | "Aprende marketing" | "Cómo vender 24/7 mientras duermes" |

## 4. ESTRATEGIA DE CONTENIDO — Funnel TOFU/MOFU/BOFU

**Skill global:** Estrategia de contenido (TOFU/MOFU/BOFU, calendarios)
**Aplica en:** `agents/strategist.md` — añade capa de funnel al calendario semanal

### Distribución Semanal por Temperatura de Audiencia

```
TOFU (Top of Funnel) — Awareness — 40% del contenido
Audiencia: No te conoce, no sabe que tiene el problema
Objetivo: Llegar a nuevas personas, algoritmo favorece alcance
Formato: Reels virales, hooks contrarian, educación básica
Ejemplos Alexander:
  - "Live shopping NO es TikTok Shop" (educa a desconocidos)
  - "La IA no te va a reemplazar" (hook viral, alcance masivo)
  - Reel de 30s con dato impactante

MOFU (Middle of Funnel) — Consideración — 40% del contenido
Audiencia: Ya te sigue, evalúa si eres la opción correcta
Objetivo: Demostrar expertise, generar confianza, nutrir
Formato: Carruseles profundos, casos de estudio, comparaciones
Ejemplos Alexander:
  - "Stack Pancake: cómo funciona" (educa a seguidores)
  - "Caso: de $X a $Y con live shopping" (prueba social)
  - Tutorial de IA aplicada (valor táctico profundo)

BOFU (Bottom of Funnel) — Conversión — 20% del contenido
Audiencia: Lista para actuar, solo necesita el empuje
Objetivo: Convertir a DM, agenda, lead
Formato: Casos de éxito específicos, oferta explícita, testimonios
Ejemplos Alexander:
  - "Quedan 2 cupos para consultoría de mayo" (escasez real)
  - "¿Listo para implementar live shopping? Escríbeme" (CTA directo)
  - Post de resultado de cliente con CTA
```

### Regla de Calentamiento Progresivo

```
Semana 1-2: Mayoría TOFU (construir alcance)
Semana 3: Equilibrio TOFU/MOFU
Semana 4: Más MOFU + 1 BOFU (cierre mensual)
```

## 5. VIRALIDAD EN REDES — Algoritmos y Patrones

**Skill global:** Viralidad en redes (algoritmos, patrones virales)
**Aplica en:** `skills/viral-hooks.md`, `agents/strategist.md` (timing)

### Factores de Viralidad por Plataforma

**Instagram 2025:**
```
SEÑALES QUE EL ALGORITMO PREMIA:
1. Guardados (señal de valor — más peso que likes)
2. Compartidos en stories (señal de viralidad)
3. Tiempo de visualización en carruseles (deslizar hasta el final)
4. Comentarios largos (más peso que comentarios de 1 palabra)
5. DMs desde el post (señal de conversión — premium)

CONTENIDO QUE EL ALGORITMO PENALIZA:
- Links externos en caption (saca al usuario de IG)
- Engagement comprado (detectado por patrones de velocidad)
- Publicación irregular (el algoritmo premia consistencia)
- Baja retención en reels (si se van en 3 seg, no distribuye)
```

**TikTok 2025:**
```
SEÑALES QUE EL ALGORITMO PREMIA:
1. Completion rate (% que termina el video — más crítico que likes)
2. Re-watches (ven el video 2+ veces)
3. Comentarios (cualquier tipo activa distribución)
4. Shares fuera de TikTok (cross-platform boost)
5. Follows desde el video (señal de conversión)

VENTANA DE DISTRIBUCIÓN:
- Primeras 2 horas: Test a pequeña audiencia
- Si ER >5% en 2hrs: Distribución ampliada
- Si ER >10% en 6hrs: Push viral potencial
```

### Patrones Virales Identificados para el Nicho de Alexander

| Patrón | Descripción | Ejemplo aplicado |
|--------|-------------|-----------------|
| **Contrarian** | Contradice creencia común del nicho | "Live shopping ≠ TikTok Shop" |
| **First-person failure** | Historia de fracaso propio + aprendizaje | "Quebré SICOMMER. Aquí el porqué:" |
| **Data drop** | Dato sorprendente sin contexto en hook | "$500B en China. $0 educación en LATAM." |
| **Behind the scenes** | Mostrar lo que nadie muestra | "Así se ve un falso live por dentro" |
| **Desmitificación** | Destruir un mito popular del nicho | "IA no es complicada. Te mintieron." |
| **Comparación visual** | Antes/después o A vs. B | "Ecommerce 1% conversión vs. Live 15%" |

### Timing Óptimo (Ajustar según analytics reales)

```
INSTAGRAM:
- Lunes: 8-10am (emprendedores en modo semana nueva)
- Miércoles: 12-2pm (break del mediodía)
- Viernes: 5-7pm (cierre semana, modo reflexivo)
- Domingo: 7-9pm (preparación semana, mood reflexivo)

TIKTOK:
- Cualquier día: 7-9am, 12-3pm, 7-11pm
- Consistencia > timing perfecto

LINKEDIN:
- Martes-Jueves: 8-10am, 12-1pm
- Evitar fines de semana
```

## 8. GROWTH HACKING — Loops de Crecimiento para Contenido

**Skill global:** Growth hacking (loops, A/B testing, funnels)
**Aplica en:** `agents/analyst.md` — capa de optimización continua

### Content Growth Loops para Alexander

**Loop 1: Educación → Comunidad → Contenido**
```
Alexander publica contenido educativo de live shopping
→ Audiencia aprende algo nuevo
→ Comparte con su red ("esto te tiene que ver")
→ Nueva audiencia llega
→ Parte se convierte en seguidores
→ Generan preguntas en comentarios
→ Las preguntas se convierten en nuevo contenido
→ Ciclo se repite
```

**Loop 2: DMs → Insights → Contenido**
```
CTA pide DMs con pregunta específica
→ Alexander recibe 50 DMs con respuestas
→ Identifica patrones en respuestas
→ Crea contenido basado en pain points reales
→ Alta resonancia porque es de la audiencia
→ Más DMs → más insights → mejor contenido
```

**Loop 3: Scraping → Análisis → Diferenciación**
```
Apify scrapea competencia cada semana
→ Analyst identifica qué está funcionando
→ Alexander crea versión diferenciada con su voz
→ Si supera al original → continuar
→ Si no supera → ajustar enfoque
→ Base de datos de patrones crece
```

### A/B Testing Framework para Contenido

```
VARIABLES A TESTEAR (una a la vez):
1. Hook (semana 1-2)
2. Formato (semana 3-4)
3. Día/hora publicación (semana 5-6)
4. Tipo de CTA (semana 7-8)
5. Largo del caption (semana 9-10)

CÓMO MEDIR:
- Métrica primaria: ER primeras 48hrs
- Métrica secundaria: Guardados + Compartidos
- Umbral de ganador: >20% diferencia

CÓMO DOCUMENTAR:
→ En outputs/reports/ con fecha y conclusión clara
→ Acumular en knowledge/competitors/ como base de datos
```
